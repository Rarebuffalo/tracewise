The red check is the easy part.

A failed run hands you an exit code and a log that can run to thousands of lines. The line that explains it is in there somewhere — between deprecation warnings, progress bars and the output of every test that passed.

So you scroll. You guess. You rerun it and hope it was flaky. Tracewise does the reading for you, and shows its work.

How it works

From a red check to a receipt, in four steps.

  1. 01

    A run fails

    GitHub tells Tracewise when a workflow run fails in a repository you've granted it.

  2. 02

    It finds the lines that matter

    A deterministic pre-pass pulls the primary error lines out of the failed job's log — before any AI is involved — and tells one failure repeated many times apart from several independent ones.

  3. 03

    It follows them into the code

    A bounded, read-only investigation reads the code at the failing commit and your push's diff. It can read, search, list and diff — nothing else — within 12 calls and 120 seconds.

  4. 04

    It posts the receipt

    Every cited file, line and link is checked against what was actually examined. The diagnosis — or an honest "inconclusive" — lands as a Check Run and a PR or commit comment.

The report

What lands on your pull request.

Short enough to read in the PR, specific enough to check. Each finding names its evidence, the confidence is stated with its basis, and a suggested fix is text — never a commit.

  • 1 Every claim links to a log line, file or diff.
  • 2 Confidence is stated, with the reason for it.
  • 3 When it can't tell, it says so — and what would help.

The difference

Receipts, not guesses.

Tracewise will

  • Cite the log line, file and commit behind every claim
  • Say how confident it is, and why
  • Say "inconclusive" when the evidence runs out
  • Ask GitHub only for: Actions, Contents and Metadata read; Checks and Pull requests write (to post its report)

Tracewise won't

  • Push commits, open pull requests or apply fixes
  • Run your code or reach other systems while it investigates
  • Keep your full logs or full source files*
  • Pretend to know when it doesn't

* As implemented today and described in the draft privacy notice, which will be reviewed before any pilot.

Questions, answered plainly.

Can I use Tracewise today?

Not yet. It's pre-release: the pipeline is built and tested offline but hasn't run on live repositories, no AI model is connected and there's no hosted service. Joining the list is how you get an invite when the first pilot opens.

What access does the GitHub App ask for?

Actions, Contents and Metadata read, to fetch the failed run's logs and the code at that commit; Checks and Pull requests write, only to post its report. You choose which repositories it can see, and can suspend or uninstall it at any time.

What happens to my logs and code?

For a failed run it reads the job's logs, the triggering commit's changes and the specific files it needs, with a short-lived token limited to that repository. Once an AI model is enabled (planned: OpenAI; not enabled yet), excerpts are sent to it with secret-like values redacted. Full logs and full source files aren't stored; the diagnosis and short excerpts are, for a limited time. All of this is described in a draft privacy notice that will be reviewed before any pilot.

Will it change my code?

No. The investigation can only read, search, list files and read diffs. A suggested fix is text in the report — it never commits, pushes or opens a pull request.

What if it's wrong?

It can be. That's why every claim links to its evidence, the confidence comes with its reason, details it can't verify are removed or downgraded, and it says "inconclusive" rather than guess. Early-access feedback is how it gets better.

Which projects does it work with?

GitHub Actions only. Its pre-pass recognises output from pytest, Python tracebacks, ruff, mypy, tsc, jest, vitest, eslint and installers (pip, npm, uv).

How is this different from an AI "fix it" button?

Tracewise doesn't write code. Its job is to show you what it found and exactly where it found it — log line, file, commit, diff — and to tell you plainly when the evidence isn't enough. You decide what to change.

What will it cost?

Pricing isn't decided. Joining the list costs nothing and commits you to nothing.

How do I get off the list?

Every email has a one-click unsubscribe, and you can ask for your signup to be deleted at any time.
