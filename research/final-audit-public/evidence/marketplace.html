CI broke. Again. Now someone has to dig through logs, trace the stack, find the line, figure out the fix.

The Plumber does that for you.

Install once. When your GitHub Actions workflow fails, The Plumber automatically analyzes the failure and posts a structured repair report — root cause, exact file and line, ready-to-apply fix — directly on your commit or PR. In under two minutes.

What it does

When a CI pipeline fails on a connected repository, The Plumber:

  1. Downloads the CI log from the failing workflow run
  2. Clones the repository at the failing commit
  3. Runs an agentic analysis through the actual codebase
  4. Posts a structured Plumbing Report on your commit or PR — in under two minutes

No config changes. No new CLI tools. No dashboard to monitor. Install once, works on every failure.

The Plumbing Report

Every report includes:

  • Root cause — not just the error message, but why the code is wrong
  • Problematic code — exact file and line number
  • Recommended fix — a ready-to-apply code change
  • For AI Agents — a structured section optimized for Cursor, Claude Code, Windsurf, and other AI coding assistants. Attach the report and say "fix this."

See real example reports →

How it works

The Plumber installs as a GitHub App and listens for workflow_run failure events. When CI breaks, analysis begins automatically — no action required from your team.

Privacy

Your code is never stored. The analysis environment — including the cloned repository and CI log — is destroyed immediately after the report is posted. Full privacy policy →
